# Milestone 1 mockups

Static screens for single-agent chat. Open each option’s `index.html`. The sample includes a reply that is still streaming.

## Option 1 — Centered column

- Concept: A Claude-style reading column on warm paper, with a quiet recents sidebar and one composer.
- Strength: The transcript is the product. A long reply stays easy to read.
- Strength: Almost no chrome, so a streaming reply reads as prose.
- Tradeoff: A computer, a tool trace, or a second agent has nowhere obvious to live.

## Option 2 — Sidebar and composer

- Concept: A ChatGPT-style split. Conversations on the left, the transcript in the center, the composer pinned to the bottom.
- Strength: Switching threads is immediate, and the composer never moves.
- Strength: The stop control on a streaming reply needs no explanation.
- Tradeoff: There is still one surface, so tool activity and a computer have to fold into the transcript.

## Option 3 — Agent and computer

- Concept: A Cursor-style workspace. Agents, the transcript, and the computer the agent is writing on.
- Strength: The reply and the file are visible in the same moment.
- Strength: The sandboxed computer already has a pane, instead of a later screen.
- Tradeoff: Denser than a chat column, and on a phone the computer steps behind the transcript.

## Option 4 — Dark assistant

- Concept: A Grok-style dark assistant. Tool-activity cards sit in the transcript, then the reply streams under them.
- Strength: Search, notes, and the draft read as work, not as decoration.
- Strength: The dark canvas stays calm, and the cards scan quickly.
- Tradeoff: Cards spend vertical space, so a phone shows less of the prose at once.
