# Agent rules

These rules are permanent. They apply to every commit and every pull request in this repository.

## 1. Authorship

No commit or pull request may name Cursor, or any other AI or coding agent, as author or co-author.

- Do not add a `Co-authored-by` trailer.
- Do not add a "generated by" line, or any similar credit, in a commit message, pull request title, or pull request description.
- The author and committer of a commit are the person who owns the change.

## 2. Pull request proof

Every pull request description must include all three of the following:

1. A visual that explains exactly what changed. A mermaid diagram of the flow or structure is enough when the change has no screen.
2. The tests that were run, with their results and output.
3. A screenshot or screen recording that proves the change works.
