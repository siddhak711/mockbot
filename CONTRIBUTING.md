# Contributing

## Attribution

No commit and no pull request may list Cursor, or any coding agent or other AI, as an author or a co-author.

- Do not add a `Co-authored-by` trailer.
- Do not add a "generated by" line, or any other authorship credit for an agent or a model.
- Do not put that attribution in a commit message, a pull request title, or a pull request description.

This rule is permanent. Agents also read it from `AGENTS.md`.

## Checks

Node.js 22 or newer.

```bash
npm install
npm run lint
npm run typecheck
npm run format:check
npm run test
```
