# Contributing

The same rules are in [AGENTS.md](AGENTS.md). They apply to people and to agents.

## Authorship

No commit or pull request may name Cursor, or any other AI or coding agent, as author or co-author. Do not add a `Co-authored-by` trailer. Do not add a "generated by" line, or any similar credit, in a commit message, pull request title, or pull request description.

## Pull request proof

Every pull request description must include:

1. A visual that explains exactly what changed. A mermaid diagram of the flow or structure is enough when the change has no screen.
2. The tests that were run, with their results and output.
3. A screenshot or screen recording that proves the change works.

## Spec check

Pull requests that change the UI or the data model must say which product-model invariants in [AGENTS.md](AGENTS.md) they touch and how the change keeps them. Reviewers flag a pull request whose screenshots or recordings contradict those invariants.

## No mock providers outside tests

No mock, stub, or fake provider may be reachable outside tests. A missing credential must fail loudly with a visible error, never a silent mock fallback. Every review greps the non-test code the pull request touches for `mock`, `stub`, and `fake` and states the result. See [AGENTS.md](AGENTS.md) section 4.

## Retry rule

Every retry of failed work must change something: the failure evidence, the worker, a fresh context, or the plan. Attempt 2 is the same worker with the failure evidence, attempt 3 is a fresh context, and after that the plan changes. See [AGENTS.md](AGENTS.md) section 5.

## Tool credentials in production

Every tool declares its credential source (env var or per-user OAuth). A pull request that adds or changes a tool lists those sources and confirms production provides each one: `vercel env ls --environment production` names only for env vars, or the OAuth path shown working live. A tool with no credential in production must fail visibly. Production uses per-user GitHub OAuth; `GITHUB_TOKEN` is for local development only. See [AGENTS.md](AGENTS.md) section 6.

## Checks

Requires Node.js 22 or newer.

```bash
npm install
npm run lint
npm run typecheck
npm run format:check
npm run test
```

GitHub Actions runs lint, typecheck, the format check, and tests on every push and pull request.
